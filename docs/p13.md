# P13 — Transport Qualification

P13 extends the private pre-publication qualification boundary without changing the canonical ACL4SSR classification graph, the six public FlClash selectors, DNS ownership, Sniffer settings, or subscription reachability policy.

## Goal

P12 improved traffic identity with HTTP/TLS/QUIC sniffing. P13 addresses the next layer: whether an automatically selected general node can actually carry the transport required by the scenario.

The general inventory remains available for explicit/manual user choice. Automatic routing is hardened immediately before publication:

1. `自动选择` is restricted to nodes that pass a live HTTPS probe through the real Mihomo core.
2. `媒体自动` and `通讯自动` are restricted further to TCP-qualified nodes with a live SOCKS5 UDP-associate path through Mihomo.

## UDP / QUIC probe

For every TCP-qualified general node whose runtime declaration does not explicitly disable UDP, P13 selects the node in a private Mihomo selector and checks its UDP path.

The probe first sends a 1200-byte unsupported-version QUIC long-header datagram to `1.1.1.1:443`. A response is evidence that the selected proxy can carry UDP/443 to a QUIC-speaking endpoint. If that short probe does not respond, a lightweight DNS UDP round-trip to `1.1.1.1:53` is used as a generic UDP fallback.

A node is therefore reported as:

- **TCP qualified** when the live HTTPS probe succeeds.
- **UDP qualified** when either the QUIC-path probe or DNS UDP fallback succeeds.
- **QUIC path observed** only when the UDP/443 version-negotiation probe receives a response.

`QUIC path observed` is intentionally not a full HTTP/3 application entitlement or throughput test. P13 validates transport reachability while keeping qualification lightweight.

## Fail-closed behavior

If no general node passes the live HTTPS admission, publication stops.

If no TCP-qualified general node has a working UDP path, publication also stops rather than publishing unsafe automatic media/messaging selectors.

Manual node choices are not deleted by P13. The qualification result only constrains the automatic selectors.

## Privacy

Production summaries expose only aggregate counts such as tested, TCP-qualified, UDP-qualified, QUIC-path-observed, and static-UDP-disabled nodes. Node names, endpoints, credentials, subscription URLs, and traffic records remain private.

## Unchanged contracts

P13 does not change:

- `runtime.dns.mode: client` or the P11 no-Fake-IP production default;
- HTTP/TLS/QUIC Sniffer settings introduced by P12;
- ACL4SSR Online rule order or the declared P10 deviations;
- the six public groups;
- browsing regional preference order and Stable/Reserve history;
- OpenAI / Claude / Gemini qualification;
- `subscription_1` browsing/AI-only isolation, the `>2x` filter, or the EMBY exclusion;
- dual Mihomo v1.19.30 / v1.19.29 validation;
- previous-good snapshot semantics;
- Cloudflare-KV-only production publication.
